#  Project Overview
This repository features a comprehensive survey data analysis designed to address a simulated business challenge using multivariate statistical techniques.

## Limitations and Scope
The results are constrained by the online sampling method used and may lack statistical reliability. However, the survey data successfully enabled the simulation of a business problem and the practical application of data-driven segmentation techniques.

## Key Methodologies
The analysis includes the following core components:
- **Dimensionality Reduction:** Factor Analysis / PCA to identify latent variables and underlying patterns in the survey responses.
- **Customer Segmentation:** Cluster Analysis to group respondents into distinct, actionable profiles based on their behavior and attitudes.
